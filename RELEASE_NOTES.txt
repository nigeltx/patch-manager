Backups beside Sources and Patches. Version 0.7.2.

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

- Each synth folder now has three folders: Sources, Patches and Backups.
- Backups are point-in-time dumps of the synth, kept to put it back as it was. They are not sources: the
  app no longer reads them into the library, so nothing in a backup shows in the patch list or reaches
  Patches. Sounds you want to keep come from Sources only.
- Library > Reorganize library… moves the backups from _Patch Manager > Backups into each synth's own
  Backups folder (Take 5 > Backups, …) and puts the empty old folder on the Studio Cleanup list.
- Initialize, Back up, Clear user slots and the Syntakt audition slot all save their dumps there.
- Initialize now saves the sounds into Sources before marking them, and never counts a sound from a
  factory bank as yours.

Factory duplicates. Version 0.7.1.

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

- A user slot holding an exact copy of a factory sound is never saved as one of yours — by Get from synth,
  Initialize, Clear user slots or Reorganize. A copy you renamed, or edited, is yours and is kept.
- This now also holds when the factory sound is in no factory file yet: any sound last seen in one of the
  synth's factory slots (Take 5 F1-F16, Sub 37 banks 1-9, Syntakt A-G) counts as factory.
- Syntakt: a sound's identity no longer includes the pool slot it was saved from. The same sound in G020 and
  in H127 used to look like two different sounds, which is how two factory copies reached Sources > User.
  The first start re-identifies every Syntakt sound; ratings, tags, crates, types and green rows follow it,
  and a Rebuild takes the duplicate out of Patches.
- Folders called Archive (where Clean up Studio.cmd puts things) are not read.
- Syntakt and Deluge files copied into Sources get tidy names (H127 BASS SLAP MY B.stsnd).

Take 5 user slots. Version 0.7.0.

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

New — design spec v1.11, sections 7.9 and 7.10. On the Synths menu, under Take 5:
- Clear user slots… writes a blank init program into all 256 user slots, U1-01 to U16-16. Factory banks
  F1-F16 are never touched. First you choose Init Program on the Take 5's panel and save it into one user slot
  (U16-16 unless you pick another); the app reads it, asks you to confirm its name, and keeps it as
  _Patch Manager > Take 5 init.syx. That sound is marked blank, so it is never kept as one of yours.
  Then every user slot is read and saved in Backups, and any sound that is in no source goes to
  Sources > User before anything is written. The plan lists every slot; nothing is written until you press
  Clear. About two to three minutes.
- Fill user slots… sends your own Take 5 patches (whose only source is Sources > User) into the user slots,
  packed from U1-01 in Patches order: Bass, Lead, Pad … then by name. Only slots holding the init program
  are used, so nothing of yours is written over. Untick any you do not want.
- Undo the last clear or fill… puts the old programs back from their backups.
- Every slot: read it, check it still holds what the plan expects, back it up, write, read back, compare.
  If a compare fails the old program goes straight back and the run stops. Stop after this slot stops a run
  cleanly.
- User banks U1-U16 are never locked, even when they hold copies of factory sounds.

Sources and Patches. Version 0.6.0.

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

New — design spec v1.10, section 4
- Each synth folder now has two folders. Sources (Factory, Paid, Free, User) keeps every pack, factory set and
  synth read as it came. Patches holds every sound once, one file each, in a folder for its type: Bass, Lead,
  Pad, Keys, Pluck, Arp-Seq, Strings, Brass, Bells, FX, Kick, Snare, Clap, Hat, Cymbal, Tom, Percussion, Unknown.
- Library > Reorganize library… moves today's folders into the new layout once, and shows every move first.
  Folders you already moved (Sub 37 > Sources > Free) are left where they are. Sample packs (Twin Shot) go to a
  Samples folder. The factory reads in _Patch Manager > Backups stay there; their factory sounds are copied into
  Sources > Factory and your own sounds into Sources > User, so your own presets are never marked factory.
  Empty old folders go on the Studio Cleanup list. The app offers this once on the first start.
- Rebuild (toolbar) brings Patches up to date with Sources and shows the plan first. Files it takes out go to
  _Patch Manager > Removed, never deleted. A second rebuild changes nothing. A file you put in Patches by hand
  whose sound is in no source is moved to Sources > User > Added by hand, so it is never lost.
- Get from synth (toolbar) reads a synth and keeps the sounds that are in no source — ones you made on the
  panel — in Sources > User, then adds them to Patches. Slots in the factory banks are left to Initialize.
- Initialize factory presets now puts the ticked factory sounds in Sources > Factory and your own in
  Sources > User (once the library is reorganized).
- Zip packs are read where they are, without unpacking.
- Sources are locked by the app and fingerprinted. Google Drive drops Windows' read-only mark (bench test 20),
  so instead every scan checks each file: one that changed or went missing outside the app is listed under
  "Sources changed or missing", and its sounds are kept as they were until you decide.
- Right-click a User source > Delete user source… (type its name to confirm; it goes to Drive's trash).
- Set type… now moves the file in Patches too; your choices are kept in _Patch Manager > types.json.
- Left pane: each synth shows Patches by type folder, with how many are on the synth, then Sources.


Patches by type. Version 0.5.0.

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

New — the same idea as the Sample Manager's BY TYPE
- BY TYPE in the left pane, with counts: Bass, Lead, Pad, Keys, Pluck, Arp/Seq, Strings, Brass, Bells, FX,
  Drums (Kick, Snare, Clap, Hat, Cymbal, Tom, Percussion), and Unknown.
- The type is the app's best guess from the patch name ("LD Super Saw" is a Lead, "BS Reese" a Bass), then
  from the tags that came with the file (Syntakt sounds carry tags), then from the pack's folder names.
  Moog's "PD …" presets are not taken as pads (PD means public domain).
- A Type column next to Name (grey italics = the app's guess), and a Type line in Details saying where the
  guess came from.
- Right-click one or many patches → Set type… to correct the guess. Your choice always wins, survives rescans,
  and "Go back to the app's guess" undoes it. Nothing is written to the patch files.
- Search: type:bass, type:pad, type:drums, -type:fx.
- The first start after updating works out the types of the whole library (a few seconds).
