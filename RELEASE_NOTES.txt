Patch Manager 0.4.2

Download the PatchManager-Setup .exe below and run it; it updates the installed app in place.

Changed
- Syntakt factory banks now default to A-G. The Syntakt's factory sounds fill banks A to G; only H is free
  (H128 is the audition slot). If an earlier version saved "A" for the Syntakt, it is read as A-G.
